The recorded evaluation process

  1. Freeze the same answer, task, supplied evidence and scenario-focused criteria. Retain exact input hashes and original workflow metrics; do not regenerate a response to match an evaluator.
  2. Independent blinded judges. GPT and Decision-1 each receive that identical packet in independent states, without router identity or the other vote.
  3. Binary votes: Accept / Do not accept. Completed model judgments use no historical confidence threshold. Technical, transport and parse errors remain statuses, not invented votes.
  4. Compare on the same saved answer. Count Accept/Accept and Do not accept/Do not accept separately, then inspect disagreements and operational failures without tuning these votes toward agreement.

Each original workflow pair supplies two different saved answers. Each answer receives two independent evaluator judgments. H2 does not compare the two different routed answers to each other. Original full-rubric judgments remain unchanged.
